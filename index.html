Robot de Rescate - Copérnico 402

Aspecto Descripción
Propósito Crear un robot de rescate capaz de explorar y localizar a los miembros del equipo científico extraviados en un entorno hostil como la selva del planeta Copérnico-402. Este robot debe permitir la recopilación de datos vitales, la movilidad en terrenos difíciles y la señalización para rescate.
Temática Robótica aplicada a misiones de rescate en zonas de difícil acceso, utilizando sensores biomédicos, control de motores y comunicación para asegurar la localización y asistencia en situaciones de emergencia en entornos complejos.
Materiales y Piezas
  • Dos mini protoboard:
    • Para montar circuitos electrónicos de forma práctica y modular.
  • Tarjeta de desarrollo ESP32:
    • Microcontrolador para control y conectividad inalámbrica.
  • Sensor MAX30102:
    • Sensor biométrico para medir signos vitales, como pulso y oxígeno.
  • Cables para conexiones: Para interconectar todos los componentes electrónicos.
  • Portapilas para batería de 9V: Fuente de energía portátil para alimentar el circuito.
  • Módulo controlador L9110:
    • Maneja la dirección y velocidad de los motores reductores.
  • Seis jumpers macho-hembra: Conexiones seguras entre el ESP32 y otros módulos.
  • Dos motorreductores amarillos:
    • Motores con engranajes para el movimiento del robot.
  • Dos diodos LED: Indicadores visuales para señales de estado o alertas.
  • Dos resistencias de 220 Ω: Limitan la corriente para proteger los LEDs.
  • Buzzer pasivo: Emite sonidos de alerta para facilitar la localización.
  • Kit acrílico de chasis para rover: Soporte estructural que incluye ruedas, tornillos, interruptor y rueda loca.
